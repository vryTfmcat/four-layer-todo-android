# 四层待办 UI 原型

Obsidian 待办插件的阶段 0 本地交互原型。它先验证注意力分层和页面流动，不读写真实 Obsidian 笔记，也不调用 AI。

## 已实现

- 正面以白板为核心，可添加、拖动和完成任务。
- 右上角翻转到背面的缓存工作台。
- 工作台包含收集箱、待办列表、缓存列表，以及三个 AI 接口占位按钮。
- 背面下四分之一显示任务存储器简略视图。
- 每个任务卡片右上角都有三点菜单，可选择移动到白板、缓存工作台或任务存储器；跳转后再选择具体放置位置。
- 任务存储器使用 Task List Kanban 风格，可自由新增任务池、添加任务，并在任务池间拖动。
- 可从任务存储器切换到外围长期对象，并查看每个长期对象关联的具体任务。
- 演示数据和手动操作保存在浏览器 `localStorage`。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

然后访问 `http://localhost:3000/`。

## 验证

```bash
npm test
```

这会完成生产构建，并验证四层核心页面能够服务端渲染。

## 朋友体验包

生成无需安装环境、解压后可以直接双击打开的朋友版：

```bash
npm run build:friend
```

输出位于 `dist-friend/`。朋友双击其中的 `index.html` 即可体验；首次打开会显示五分钟体验路线，文件夹内另有体验说明和反馈问题。

## 当前边界

- AI 按钮只显示“接口已预留”的反馈。
- 页面使用演示任务，不连接真实 Vault。
- 对应的可安装插件工程位于 `../插件/four-layer-todo/`。
