# 四层待办 · 朋友体验说明

谢谢你帮忙体验。这个原型想验证一件事：完整任务库仍然存在，但日常界面是否可以只把人的注意力放在当前工作现场。

## 如何打开

1. 解压整个体验包。
2. 双击 `index.html`。
3. 不需要安装 Obsidian、Node 或浏览器插件。

## 建议体验路线

1. 看看首页白板是否能让你理解“我正在做什么”。
2. 点击右上角翻转按钮，进入缓存工作台。
3. 试着把待办移入白板，或把缓存任务恢复到白板。
4. 在背面下方进入任务存储器，看看完整 Kanban。
5. 切换到“外围长期对象”，观察兴趣、目标和长期想法是否应该与任务分开。
6. 点击 AI 按钮，感受未来智能整理功能放在这个位置是否自然。

## 需要知道

- 所有任务都是演示数据。
- 所有修改只保存在你当前的浏览器中。
- AI 按钮目前只显示占位反馈，不会联网。
- 这不是最终视觉设计，重点是页面层级和任务流动。
